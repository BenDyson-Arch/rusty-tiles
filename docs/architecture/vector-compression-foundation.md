# Vector compression foundation preparation

Preparation is in progress under #126. No production codec or in-place operation
has been implemented or accepted by this checkpoint. Foundation decisions and
focused probes precede implementation; separate nonauthor final-source and
platform acceptance follow it.

C1 JSON/payload integrity is accepted through [PR #153](https://github.com/BenDyson-Arch/rusty-tiles/pull/153),
reviewed head `4dc8f0c04dd5a98420768d05c6787f3baa49bb75`, develop merge
`f5401dd120441b4f9aac5ad229dbfffe03fe4428`. The merge has exactly the reviewed
tree `57095507d251e4f2fcb826cee367fa72bd306158`. Its independent remote review,
97 lossless evidence records, five actual wheel hashes, ten installed-Python
reports and four official Blender report pairs are retained in this subsequent
source epoch. All 21 applicable checks passed; two prescribed skips remain skips.
The C1 review retains partial remote descriptor observations and distinguishes
job-computed binary/Blender pins from locally rehashed downloaded wheel bytes.

Full A2 implicit rewriting remains held on its documented normative external
template question. The next dependency-ready foundation is one lossless codec
for physical views in the complete currently generated vector domain, consumed
by the real vector producer and a captured-file in-place operation using F0
Replace. The format owner knows no paths or jobs; standalone owns source capture,
permissions, final source recheck and publication. The producer remains inside
its existing Attempt. The old compression implementation earns no retention
from historical tests or generated bytes alone.
