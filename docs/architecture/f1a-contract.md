# F1a local static mesh contract

Implementation contract for [#117](https://github.com/BenDyson-Arch/rusty-tiles/issues/117), agreed before coding against accepted F0 `519e8c1`. This is the bounded first mesh milestone, not completion of all mesh functionality or permission to release 0.4.0. Existing and new algorithms must pass independent evidence gates. Broader scope remains in #113 and the [post-F0 plan](https://github.com/BenDyson-Arch/rusty-tiles/blob/docs/113-next-foundation-scopes/docs/architecture/next-foundation-scopes.md).

## Facade and adapters

```rust,ignore
let request = MeshRequest::local_gltf(input, output, leaf_triangles)
    .with_policy(OutputPolicy::CreateNew);
let result = mesh_to_archive(request, &RunControl::default())?;
```

Root exports `MeshRequest`, `MeshResult`, `MeshReport`, `mesh_to_archive`. Request owns private paths, positive explicit `usize` leaf-triangle limit and OutputPolicy (default CreateNew). Builders collect values; the operation validates once. No numerical convenience default, coordinate guessing, context/options framework, new report registry or public source/partition/codec types. Output must be `.3tz` or `.3dtiles.zip` and must not alias source. Result owns resolved absolute output, typed report, and F0 cleanup diagnostics. Requests use one F0 single-use RunControl; invalid requests consume that attempt without creating output work.

CLI: `mesh-local-to-3tz -i INPUT -o OUTPUT --leaf-triangles N [--force]`, with existing JSON/progress transport options. Python: `mesh_local_to_3tz(input, output, *, leaf_triangles, force=False, callback=None)`. Both construct the same request and use F0 observer/error/exception semantics. The named operation explicitly declares local glTF coordinates; there is no omitted/default coordinate mode to guess. Legacy broad `mesh-to-3tz`/`mesh_to_3tz` remain distinct unreviewed operations, not fallback routes for rejected F1a inputs.

## Finite source profile

All document objects must pass a strict key/semantic allowlist, including objects outside the rendered scene. Valid glTF outside this profile returns Unsupported; malformed envelope/schema/data returns InvalidInput. No unsupported semantic is discarded merely because a small file would fit one leaf. Names may be accepted as descriptive labels but are not pickable identities and are not forwarded; asset generator/copyright and object names carry no preservation promise in this milestone. `extras`, `extensions`, declared extensions, cameras, animations, skins, morph targets, images, textures, samplers and external/data URIs are Unsupported anywhere in the document.

- **Container:** GLB version 2; exact header/file length, one JSON chunk followed by one BIN chunk; no trailing or unknown chunks. JSON padding is spaces; BIN may have at most three zero padding bytes beyond buffer byteLength. Asset version is 2.0, minVersion absent or 2.0. Exactly one buffer, embedded in BIN, with valid byteLength and no URI. Every bufferView/accessor range, checked count/stride arithmetic, component alignment and relevant reference is validated against actual payload, not just declarations. Unknown chunks are outside profile; truncated/overlapping/out-of-range data is malformed.
- **Scenes:** choose declared default scene, otherwise the sole scene; absent or ambiguous scene selection is Unsupported. Render only the selected scene. Its graph is a strict finite tree/forest: roots are distinct, children have at most one parent, no cycles/duplicate child references. Other scene and node records still satisfy the profile. Mesh instancing by distinct nodes is supported and counted for each selected instance. No implicit traversal of every node when scenes are absent.
- **Primitives:** TRIANGLES (mode absent means TRIANGLES); POSITION required; NORMAL optional; no other attributes or targets. Indexed u8/u16/u32 SCALAR or unindexed consecutive vertices; count divisible by three, nonempty, every index valid. POSITION/NORMAL are f32 VEC3, non-normalized, nonsparse accessors. Valid aligned interleaving and byteStride are supported. Normal count equals position count. POSITION min/max are required and checked against decoded source values; all provided accessor bounds have correct shape/finite values and enclose decoded values. Missing required data or inconsistent counts are InvalidInput. Sparse/compressed/quantized data are Unsupported.
- **Materials:** primitive material absent preserves glTF's absent/default material, otherwise selects an existing material. Supported core keys are name, pbrMetallicRoughness, emissiveFactor, alphaMode, alphaCutoff and doubleSided; no normalTexture, occlusionTexture, emissiveTexture or other texture field. pbrMetallicRoughness supports baseColorFactor, metallicFactor, roughnessFactor only. Preserve presence/omission and validated values for these semantic fields. Factors have specification-valid finite ranges; baseColorFactor length4, emissiveFactor length3, metallic/roughness [0,1], alphaCutoff nonnegative finite, doubleSided boolean. OPAQUE (including omission) and MASK supported; BLEND is Unsupported because regrouping cannot promise source draw order. No invented PBR defaults in serialized material JSON; names may be omitted as described above.
- **Transforms:** node keys name, mesh, children and either matrix or TRS. Quaternion XYZW components are in [-1,1] and norm differs from one by at most 1e-6, then normalize; malformed/nonfinite quaternion or both matrix and TRS are InvalidInput. Matrix is column-major finite affine, last row [0,0,0,1], decomposable to TRS: pairwise column orthogonality within relative 1e-6. Sheared matrices are outside profile; a zero/singular or severely conditioned transform is Unsupported. Compose local T*R*S, global parent*local in f64. For accumulated linear matrix, abs(det)/(product of column lengths) must exceed 1e-12; finite intermediate arithmetic required. Reject singular normal matrices even where source normals are absent, rather than silently deleting collapsed geometry.
- **Normals/reflections:** source normals finite and unit length within 1e-4; normalize then apply accumulated inverse transpose and normalize in f64. Missing NORMAL stays missing. A negative global determinant reverses each baked triangle's second/third corners (and associated normals), preserving front-face orientation after transforms are baked. Preserve exact-zero/collinear source triangles and their multiplicity; no deduplication or automatic repair.

The material key list is exactly the concrete keys above; there are no generic normal/occlusion scalar factors in core glTF. A source decoder may use a schema library as additional validation, but eligibility, actual byte ranges and numeric semantics remain explicit checks. GLB/parser agreement is not independent correctness evidence.

## Numeric and admission contract

Local source and transformed position components must be finite and abs<=1,000,000 metres. Source glTF metre/Y-up semantics and node composition follow [Khronos glTF 2.0 sections3.4/3.5.3](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html). Compute in f64 then store nearest representable f32. Per position component, storage difference from computed f64 must be <=max(1e-6 metres, abs(value)*2^-24); normal component difference <=2e-7. Tolerances describe storage against the f64 calculation, not a universal bound on all floating-point transform evaluation. Independent analytic fixtures separately test transform accuracy. Unsupported numeric domain/conditioning is reported, not clamped. Authored/source normal normalization is intentional semantics above.

Hard profile admission ceilings (not configurable processing defaults): source32MiB, JSON1MiB, nodes4096, selected hierarchy depth128, materials256, primitives4096, sum of all declared accessor counts1,000,000, sum of all source mesh primitive triangles100,000, expanded selected-scene triangles100,000 and output leaves4096. Whole-document count ceilings apply even to unselected data; overlapping accessors or repeated mesh declarations cannot bypass bounded validation work. Read at most source ceiling+1 byte before allocating/processing further; declared payload counts and expanded instance count checked before expansion. Serial bounded whole-file/triangle materialization is permitted; no workers, constant-memory or byte-budget claim. Each encoded leaf has <=leaf_triangles; all source triangles count, including degenerates. If that limit would require more than4096 leaves, fail Unsupported before final-output staging. Source/JSON/geometry/leaf ceilings are deliberate initial engineering limits and require measured RSS/scratch/descriptors on boundary workloads before acceptance.

Private source IR is `Geometry { triangles: Vec<Triangle>, materials: Vec<validated material JSON>, source_bytes }`; `Triangle { positions:[[f32;3];3], normals:Option<[[f32;3];3]>, material:Option<usize> }`. This triangle-expanded representation has one bounded owner; it is not a public mesh schema. A checkpointed decoder takes bounded bytes and returns owned validated geometry. No mmap, external imports, legacy Scene or hidden source reread in this slice.

## Output semantics and report

Partition selected geometry into real deterministic spatial leaves, preserving coincident-triangle multiplicity, corner normals and material semantics. The hard triangle limit must hold even when all centroids coincide; total ordered triangle membership is a valid deterministic tie break. No simplification, atlas, texture encoding, meshopt, parent content/proxy, implicit hierarchy, metadata/picking or directory output.

Emit GLBs with baked local Y-up geometry. Tile bounding volumes are computed from **stored** f32 positions in tile Z-up frame `(x,-z,y)`; apply the glTF Y-up conversion exactly once. Bounds enclose decoded vertices; ancestor/root bounds enclose descendants, including degenerate zero extents. Flat explicit hierarchy: contentless root, REPLACE, one child per leaf, leaves geometricError0. Root and top-level geometricError are `max(1.0 metres, root-box diagonal)`; this is a declared omission/selection metric for routing to full-detail leaves, **not** a measured simplification/Hausdorff upper bound. A real-viewer near/far camera/SSE test must establish expected traversal for the chosen metric; formula alone does not prove rendering. See [OGC3D Tiles1.1](https://docs.ogc.org/cs/22-025r4/22-025r4.html), glTF coordinate conversion and refinement provisions, with independent oracle provenance recorded at acceptance.

Exact archive inventory: tileset.json, conversion.json, one accepted GLB per leaf and generated 3TZ index. No scratch/rejected candidate/extra source content. Use private F0 archive codec and staging/publisher under the existing attempt, never public package() with an already-used control.

`MeshReport` serializes snake_case fields: schema_version=1, profile="f1a-local-static-glb-v1", coordinates="local-gltf", source_bytes, triangles, leaf_tiles, leaf_triangles, routing_geometric_error_metres. Counts/bytes/limit use u64 in the report; no timings/global counters or inferred fields. Serialize the same typed report to conversion.json and return it. These names define this milestone's report, not a universal report schema. Result contains output/report/cleanup_diagnostics; no redundant configurable output-kind field.

## Lifetime, failures and proof gate

One F0 Attempt spans pure request validation, read-only source/destination binding and decoding, planning, private workspace/encoding, report/archive finalization and publication. Resolve checked absolute native source/destination identities before the first user callback; all I/O uses them. Preparation/eligibility failures create no output directories/scratch/staging. Drop bounded source bytes after decode. Consumer owns its serial geometry/workspace/inventory; runtime owns no converter/source/report semantics.

Consumer removes workspace explicitly after archive serialization and before final ready_to_publish observation/seal. Required cleanup failure aborts before commit with retained path and causal diagnostic; after file commit, F0 temporary-name diagnostics remain successful results. All observer calls finish, admission closes, candidate sync/seal succeeds, then one synchronized permission grant installs the file. No controlled callback/signal check or required report/source/output reread after commit. Use existing JobFailure classifications: InvalidRequest, InvalidInput, Unsupported, Io, Conflict, Cancelled, ObserverFailure, InvalidState; do not flatten parser/source failures into adapter policy. The first gate-selected fatal cause remains primary.

Acceptance needs independently encoded/decoded fixtures and sensitive corruption controls: complete oriented triangle multisets and material/normal mapping; nested/negative/nonuniform transforms; duplicate/degenerate triangles and instancing; declared-versus-actual BIN/accessor bounds; unsupported semantics independent of source size; hard leaf counts; conservative content/root bounds; actual viewer routing. Rust/CLI/installed-wheel parity, source/destination alias and callback-CWD tests, source/encode/report/archive/cleanup faults, cancel/observer/reentry/concurrent runs and final exact report/inventory are mandatory. Existing validate/goldens are not these oracles. Measure admitted boundary resource cases and record platform/toolchain/features; unavailable acceptance environments are unverified, not passed.

Stop at this profile. #120/#125 own numerical/format oracle breadth; #121 owns texture/material breadth, external resources, LOD/implicit/picking and optimization; placement/horizontal CRS and all currently advertised mesh use cases remain explicit pre-release support/removal decisions under #113. Legacy retention or deletion is not authorized merely by F1a success.
