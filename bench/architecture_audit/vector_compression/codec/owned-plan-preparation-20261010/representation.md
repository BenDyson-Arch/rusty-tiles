This package proposes one concrete Plan representation and permits only an isolated Rust probe. No prototype target, compiler, model or evaluator has been executed by the author. C1 accepted merge f5401dd is the prerequisite already met; P2 whole-owner reconciliation, P3 full generated semantic coverage, P4 adapter causality and P5 lifecycle remain separate gates. Unescaped keys explicitly borrow through visit_borrowed_str; escaped keys receive one exact fallible String. Each consumed root/buffer/physical-view property occurs once and contributes a distinct admitted value node, so arena.len<=K. This deliberately reserves all actual K, including opaque unconsumed nodes; it never reserves configured max_nodes. The flat arena replaces duplicate per-object vectors/maps and owned copies of plain keys. Root/buffer Span indexes live in the Plan header; every physical PreparedView retains its own Span and real source/action/consumer fields. Shared references select the same descriptor; distinct overlapping view indexes remain distinct.

No new JSON lexer or Value transform is introduced.
