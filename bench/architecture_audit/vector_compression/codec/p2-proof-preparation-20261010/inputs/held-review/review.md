## Decisions settled by this review, subject to their stated proof gates

1. **One pure physical-view codec; one actual operation owner.** Retain a consumed private borrowing plan, one descriptor per view object, exact accessor-window/role checks separate from physical `count=length/stride`, and generic tagged checkpoint errors. Standalone owns source paths/capture/recheck/F0 Replace. Existing vector production supplies its existing Attempt and private bytes. No nested compression run, per-view pool, full payload inspector, public IR, registry or format/runtime dependency cycle is justified.
2. **Preserve the full generated semantic domain.** FLOAT positions; padded normalized U16 positions and authored dequantization; padded U16/f32 feature IDs/table associations; point, line restart, polygon offsets/loops and fill content; BOOLEAN/INT64/FLOAT64/UTF8/string offsets/noData; and ordered exact JSON-string list fields are mandatory. Authored UINT64/native structural-array fixtures independently extend raw preservation evidence; they do not prove that the current writer authors those forms. Upstream source/geometry correctness is a separate gate.
3. **Raw JSON is the source of truth.** Retain admitted `RawValue` subtrees and targeted serializers for root/buffer/view bookkeeping. Opaque number lexemes/schema/extras/node values must not pass through `Value`. Precisely define permitted changes: container framing/padding, selected buffer/layout and meshopt declaration fields; untouched raw value subtrees remain byte-exact. Normalization of custom-serialized object keys/whitespace outside those subtrees must be stated and audited, not accidentally claimed as full source-JSON byte identity. Count before exact final GLB reservation and emit directly without a separate JSON Vec.
4. **Admit valid shared layouts without false validity rules.** The retained meshopt primary only requires extension stride to match parent stride *when the latter is present* and decoded whole-view length to equal codec count times stride. Core accessor windows can differ in offsets/counts. Explicit parent stride or unanimous natural effective stride is deterministic compression policy. Metadata/image consumers, conflicting stride interpretations, partial tails and selected strides outside positive/divisible-by-four/at-most-256 remain raw after validity checks. The first draft omitted that last condition; final codec draft corrects it. Tight U8/U16 scalar/vector and padded matrix cases require sensitive controls. Index/vertex role mixing remains independently invalid under core; ordinary distinct overlapping view objects are preserved and charged separately.
5. **Keep bounded existing-compressed identity, not a general decoder pipeline.** The operation needs to cover admitted generated compressed results and repeated invocation. A canonical embedded-buffer-plus-virtual-fallback ATTRIBUTES/NONE plan can validate each compressed stream once and copy the original GLB unchanged. This is real bounded work, not magic no-op trust. Validate fallback coverage/ranges/declarations and raw metadata once; never read virtual bytes as embedded source. Extract only an actual consumed private C1 number/stream helper after C1 acceptance and fresh source/ABI review. Do not retain all decoded arrays or use full C1 payload semantics. Other valid mode/filter/buffer graphs stay Unsupported. All-raw identity uses the same minimal plan state; owned candidate identity bytes require another `I` allocation while standalone capture remains alive.
6. **Declare excluded external representations early.** Unknown extra chunks, valid sparse accessors, extra/external/data-URI buffers, unknown declared or actual extension occurrences at applicable core positions, any image URI and external metadata schema URI are Unsupported before mutation. Nonexistent references/malformed consumed structure are InvalidInput. Known core/extension associations and arbitrary raw schema/extras survive. Do not mistake an application key named `extensions` inside extras/schema for a core extension occurrence. No arbitrary application protocol using absolute buffer byte offsets is promised.
7. **Resolve padding at format emission.** Pinned structural metadata primary lines 523–528 requires 8-byte chunk boundaries and allows up to seven zero BIN slack bytes. First drafts' universal four-byte formula contradicted that declared domain. Final codec chooses core `T=28+align4(J)+align4(U)` versus metadata `j8=align8(20+J)-20`, BIN origin `28+j8`, and `T=28+j8+align8(U)`. This absolute-boundary interpretation is arithmetically consistent and must receive a primary/consumer-backed framing probe. Relative view/component alignment is a separate invariant. Current `glb::encode_glb` uses four-byte framing; no retention of that emission helper is justified for metadata bridge/output without correction. Old generated bytes cannot automatically earn valid identity admission under a stronger envelope.
8. **Retain F0 stable-namespace named-entry Replace.** Capture one absolute spelling/canonical source path and immutable bounded bytes before observers. Hold identity; after the final observer recheck spelling, leaf/type/identity and exact bytes with bounded cancellation-aware comparison. Close source handles and events before seal/publication. Hardlink aliases/open original handles retain the original object; only the selected entry receives the new one. Same-target writers, hostile namespace changes and compare-and-swap promises remain outside the contract; deliberately demonstrate the final-check/install race. Preserving success despite postcommit diagnostics and retaining uncertain temporary names follows F0.
9. **Correct Windows portable-permission scope.** Locked `tempfile 3.27.0` Windows `persist` calls `SetFileAttributesW(candidate, FILE_ATTRIBUTE_NORMAL)` before `MoveFileExW`. Consequently preseal copied readonly permissions cannot be promised to survive unchanged F0 publication. Smallest correction: Windows readonly source is Unsupported before observers/candidate; writable source permissions remain the admitted Windows domain. Unix portable permission copying remains subject to platform controls. Do not clear the original target's attributes or apply permissions after commit to simulate preservation. No F0 publisher rewrite is needed for this slice.
10. **One minimal typed runtime extension.** Add `JobErrorKind::ResourceLimit` with explicit CLI category and installed producer-Python `ResourceLimitError`/kind mapping. Preserve codec/checkpoint causal errors through the consumer; no string classification. Standalone native failure under an admitted plan is InvalidState with codec cause. Malformed/out-of-profile producer-authored bytes similarly indicate its internal producer boundary, whereas a resource refusal remains ResourceLimit and can never become FeatureRejected/skip_invalid. Preserve first accepted abort versus later causes; publisher owns postpermission failures. Rust plus migrated CLI standalone is sufficient now; no speculative standalone Python operation is required. Installed producer Python remains an actual consumer gate.

Individual cap maxima need not simultaneously fit the estimate. Do not reserve maxima for tiny inputs. Cap checks cover exact unsigned/host/isize/u32 conversions and every count, sum, range, alignment and codec bound before relevant allocation. Recoverable owned reservation failures are ResourceLimit; pinned serde's infallible internal allocation remains an explicit abort proof limit, not graceful failure evidence.

Retain the general locked bound with checked arithmetic: `b=min(256,16*floor(8192/(16*S)))`, `B=1+ceil(N/b)*S*(S/4+ceil(b/64)+b)+max(32,S+S/4)`. `R+sum(B)+7V` conservatively bounds per-view alignment; compute matching final chunk padding explicitly. Fallback byteLength is virtual and never a resident decoded buffer. Both reserved compressed BIN and final GLB must coexist in the estimate when the chosen layout copies BIN. Identity charges snapshot plus owned candidate and bounded one-view decoder scratch; provisional `2D+3` follows aligned backing plus byte copy, not retained total decoded storage. Producer peak is the maximum of bridge and codec phases, with transferred bridge input counted once; old Value/BIN, geometry/worker state and actual clones are added wherever alive. No process-RSS or whole-producer memory claim follows from a codec estimate.
