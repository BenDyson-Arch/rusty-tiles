# Vector compression preparation

These are immutable audit, draft-contract, independent precode-review and proof
preparation epochs. No production implementation or whole-slice acceptance is
established. See [current checkpoint](../../../docs/architecture/vector-compression-foundation.md).
Original source identities and unexecuted classifications are preserved; they
must not be relabeled as current accepted executions.

The copied P2 package keeps its original integrity pins and absolute execution
provenance. Its original external path remains the coordinator execution source.
New actual evidence belongs in a distinct directory with an exact accepted merge,
source, compiler, dependency and executable receipt. Existing invalid templates
are not executable acceptance records. A passing arithmetic model or isolated
scaffold cannot establish production fidelity, defaults or publication behavior.
