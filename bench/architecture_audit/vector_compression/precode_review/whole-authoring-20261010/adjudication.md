## Chosen outcome and source domain

Author one private immutable-byte codec, consume it from the real vector
producer under its existing Attempt, and expose one intentional Rust captured-file
in-place request/result using F0 named-entry Replace. Migrate the existing hidden
CLI worker; add no new standalone Python feature. Installed Python remains a
real producer consumer. No public IR, full payload inspector, nested operation,
per-view pool, generic registry or size-triggered uncompressed fallback belongs
to this slice. Full A2 is independent held work, not a codec prerequisite.

The compression invariant is full logical physical-view byte preservation,
including padding, order and declared core/known-extension associations. Source
JSON admission borrows RawValue; untouched values retain their original lexemes.
Targeted root/buffer/view keys and surrounding whitespace may be reserialized.
No geometry reordering, quantization, world/CRS accuracy, complete metadata
meaning, arbitrary extras byte-offset protocol or complete glTF validation is
claimed. Check consumed structure, graph references, component alignment,
accessor windows, supported declarations and bounded compressed-stream integrity.

All currently generated semantics remain mandatory: raw/quantized positions and
their node transform, padded U16/f32 IDs and table links, point/line/restart/
polygon-hole/multiple-polygon/fill roles, BOOLEAN/INT64/FLOAT64/UTF8/UINT32 offsets,
noData and ordered exact-integer list strings. Independent external preservation
includes UINT64/fixed and variable structural arrays, compatible repeated
references, interleaving, core scalar/vector/matrix layouts, shared raw roles and
partial final matrix padding. Distinct overlapping view objects are preserved
and charged separately; references to the same view use one descriptor/charge.

Uncompressed input has one no-URI embedded buffer0. Existing-compressed identity
admits only the selected canonical buffer0 plus no-URI virtual fallback buffer1,
ATTRIBUTES/NONE, with all placeholder references covered and bounded streams
validated. It copies the original complete GLB unchanged after scratch drops.
All-raw identity likewise copies unchanged bytes with no invented declarations.
No virtual fallback storage is allocated. Any existing compressed view selects
this identity policy, not partial recompression. Unsupported valid containers,
extra chunks/buffers, sparse representations, unknown actual/declarations,
external image/schema URIs and other modes/filters receive explicit Unsupported;
malformed envelopes, dimensions, references and corrupt bitstreams receive
InvalidInput. Scan finite applicable core positions; schema/extras contents remain
opaque, including application keys named extensions. Unsupported is a deliberate
finite source domain, not omission of a currently generated semantic role.

After independent window validity, metadata/image/shared raw roles stay Raw.
Otherwise select a physical ATTRIBUTES stream only for an agreed positive
divisible-four stride <=256 and divisible whole-view length. Counts/windows of
individual accessors need not equal physical stream count; absent-parent packed
windows must not resurrect C1's corrected effective-stride equality. Valid
heterogeneous natural strides, ineligible U8/U16 layouts and partial matrix tails
stay Raw by deterministic policy. Native failure never triggers a cheaper retry.

## Selected finite default policy and requested-storage schedule

The nine values below are chosen for source authoring as finite independent
policy caps. They are not empirical RAM/RSS promises or completed default-corpus
acceptance. Combined preflight may refuse below every individual maximum;
conservative encoded/output bounds may refuse bytes that would ultimately fit.
Larger finite Rust requests are explicit; producer uses the same one resolved
profile. A larger vector max_bytes does not bypass codec limits or change the
meaning of exact final content size.

| Limit | Chosen authoring default |
| --- | ---: |
| Captured source bytes | 33,554,432 |
| JSON bytes | 1,048,576 |
| JSON depth, root zero | 64 |
| JSON value nodes, keys excluded | 65,536 |
| Physical views | 4,096 |
| Accessors | 4,096 |
| Aggregate unique logical/decoded view bytes | 33,554,432 |
| Candidate GLB bytes | 67,108,864 |
| Estimated operation-owned requested working bytes | 134,217,728 |

Require positive byte/node/cardinality caps; depth zero is valid. Check host,
isize, u32 and all arithmetic before allocation/native entry. Tiny inputs reserve
actual cardinalities, never configured maxima. Recoverable owned reservation
failures are typed ResourceLimit; serde internal allocation abort, allocator
overhead, OS/TLS/cache/native stack and user callback allocations are outside a
graceful OOM or total-process-memory claim.

## Causal failures and publication sequence

The pure codec has Format(InvalidInput/Unsupported/ResourceLimit), native
EncodingFailure(stage), and exact generic Checkpoint(E). It imports no runtime,
path, report defaults or publication. Standalone maps format causes directly,
EncodingFailure to InvalidState, I/O to actual Io/path/OS cause and detected
source changes to Conflict. Internally authored malformed/unsupported producer
bytes map to InvalidState, resource refusal remains fatal ResourceLimit through
fitting and final encoding, and checkpoints preserve the original Attempt cause.
No FeatureRejected, skip_invalid, message substring or invented I/O mapping.
Add only the small causal constructor/category and installed producer-Python
ResourceLimitError/kind mapping actually needed by these callers.

Standalone validates limits/path, claims one Attempt, resolves supported F0
publication and freezes absolute spelling/canonical source/parent before
observers. Admit a regular non-symlink leaf; hold opened identity and capture
bounded immutable bytes read-only. Windows readonly is Unsupported before
observers/staging; never clear original attributes. Unix explicitly copies
admitted portable Permissions to the complete private candidate before sealing.
No inode/timestamps/owner/ACL/xattr or special-bit guarantee is added.

Encode/write one staged candidate, freeze all receipt serialization, invoke final
ready observer, then recheck selected spelling/canonical path, leaf type, held
identity, length/mtime/permissions and exact bytes with stable before/after read
metadata. Catch same-length changes with restored mtime. Close held source and
identity handles, close events, sync/seal and consume named-entry Replace.
Detected mutations are Conflict; real I/O retains its OS/path cause. CWD changes
cannot redirect fixed paths. Hardlink aliases/old readers retain the old object.
Same-target racing writers and hostile namespace changes are outside the stable
domain: Replace is explicitly non-CAS, and a competitor after final recheck can
be overwritten. No atomic conditional update or crash durability is promised.

Precommit staging.fail owns cleanup and secondary/retained-path diagnostics.
After install, committed success cannot be rewritten by cancellation, adapter
output or cleanup diagnostics. Never unlink a reoccupied ownership-uncertain
temporary name. Callbacks run before event closure/seal; bounded JSON and one
native view are admitted indivisible units, not instantaneous cancellation.
