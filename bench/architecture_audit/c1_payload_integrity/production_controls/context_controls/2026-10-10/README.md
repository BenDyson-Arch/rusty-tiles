# Additive actual-C1 context controls, 2026-10-10

Prepared independently from production and its test helpers. These are inputs
and declared expectations; root owns compilation and execution receipts. No
target execution or acceptance is asserted by this preparation. The original
205-control driver/private module/manifest/bundle remain frozen and unchanged.

[generate.py](generate.py) uses only Python's standard library to construct
literal JSON, GLB2, modern28-byte b3dm, binary subtrees, metadata columns and
stored3TZ archive records. The independently declared baseline payload is one
zero FLOAT VEC3 POINTS accessor: three scalar components, one primitive, one
vertex. Tables requiring `_BATCHID` use BATCH_LENGTH1 and an additional viewless
UBYTE SCALAR ID0, satisfying the pinned wrapper rule while leaving table
semantics uninspected. Every payload also exercises the actual borrowed
structural metadata schemaUri path to an independently supplied schema document.

The twelve context fixtures isolate root/external tilesets, both ordinary-root
and payload metadata schema documents, conversion reports, local glTF, GLB JSON,
b3dm feature/batch table JSON and embedded GLB JSON, binary subtree JSON and a
JSON-encoded nested metadata extras string. Each target has opaque arrays and
nested values that strictly dominate every other parsed document in supplied
bytes, root-inclusive logical nodes and root-zero maximum depth. The generator
independently counts these facts using only the literal decoded JSON tree; keys
are not nodes. Each GLB/table/subtree's supplied alignment padding remains part
of its measured bytes. Nested extras bytes are the exact UTF8 metadata column
slice, separately measured from outer subtree JSON. Equality and one-less runs
use the same valid source archive.

[context_controls.rs](context_controls.rs) calls the actual private C1
`validate::inspect_selected` entry with all fifteen ValidationLimits fields
explicitly supplied. It introduces no public limit option and does not call
private format owners instead of the real C1 pipeline. Twelve tests perform
72 context executions: each of bytes/depth/nodes admits at equality and returns
typed ResourceLimit at one less. A thirteenth test performs10 real-C1 aggregate
executions. Same member URI and resolved dot-path alias require only three
successfully charged components; distinct byte-identical member names require
six. A shared POSITION accessor across two primitives gives vertices2 and
primitive count2 while charging three components. An unused viewless accessor
still contributes one additional component. Equality succeeds and one less
fails through the actual Check/cache owner.

Every positive compares the complete independently declared public report:
tiles/contentReferences/entries, sorted payload accessor/primitive/vertex
counters, all thirteen checks, exclusions and all fifteen selected limits.
Schema references are included in source members and expected entry counts.
Every execution compares source archive bytes before/after and emits structured
case/fact/category/input/selected-limit/report-hash evidence for root's captured
test log. Categories are matched by enum identity, never diagnostic text.
