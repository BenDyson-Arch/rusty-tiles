## Static source findings

* `content_integrity::{json,payload}` is private and owns immutable format
  meaning. The old validator-owned implementations are removed. Production
  private code imports neither validation types nor archives, paths, reports,
  jobs or frontend policy. Test-only archive fixtures do not change that graph.
* `validate::inspect` selects the public fixed profile once. `content_limits`
  maps exactly JSON bytes/depth/nodes, member bytes, decoded bytes and accessor
  components, with checked host conversion. The other nine public fields keep
  their actual owners. Nested payload/table/implicit calls introduce no default
  construction or aggregate reset.
* Shared JSON admission checks inclusive bytes, root-zero depth and root-inclusive
  logical nodes; decoded duplicate keys and scalar Unicode are checked. Root
  grammar/trailing-token admission precedes container traversal. Children are
  charged before RawValue skip/retention, not twice. Immediate-container faults
  deliberately precede descendant faults. The decoder/key set is dropped before
  descent; LIFO reversal preserves left-to-right descent. Ordinary Value derives
  only after admission, preserving existing variants/marker objects; valid
  unrepresentable numbers receive typed Unsupported. No arbitrary_precision,
  normalization, number-marker rewrite, sidecar registry or full payload DOM
  appears in the actual payload path.
* Fixed borrowed record visitors preserve missing versus present-null fields.
  Arbitrary attributes are gathered in one object pass. Exact unsigned lexemes
  are interpreted before float conversion: native or mathematical Overflow,
  with zero/exponent/trailing-zero handling and no power expansion. Count and
  declared-buffer work gates use ResourceLimit; references, offsets, layout
  enums and uint32 BATCH_LENGTH use InvalidInput. All actual consumed integer
  paths, including stride fallback and target comparisons, use this mechanism.
* Primitive mode admits schema domain 0..6 before host conversion. Defined
  outside-profile modes 2/5/6 are Unsupported; undefined or huge modes are
  InvalidInput. Viewless nonsparse accessors retain decoded zeros and finite,
  shaped bounds while exempting declared-extrema equality and any invented
  cross min/max order. FLOAT declared bounds round to binary32, then must remain
  finite. Stored bounds still compare against decoded values. This follows the
  separately recorded component-bounds decision and makes no new exact lexical
  integer-bound claim.
* Accessor component and all declared-buffer plans complete before the first
  resolver. The minimum per-payload/remaining aggregate component allowance is
  propagated. Actual buffer/image remainder reaches the C1 archive-size and
  total-read preflight before allocation/read; returned length is checked again.
  Repeated declarations charge actual returned bytes repeatedly. Ordinary view
  bytes, overlapping views and meshopt output share one logical view pool;
  data-buffer individual decode admission remains distinct from that pool and
  from actual buffer/image bytes.
* Base64 uses conservative individual admission, then canonical standard
  alphabet/padding/trailing-bit validation, exact remainder admission and an
  exactly requested output. Padded AA==/AAA= are not rejected by comparing a
  conservative estimate to the actual remainder. Meshopt admits checked output,
  rounded aligned backing and simultaneous copy arithmetic before allocation
  and FFI decode. Final partial words append only their needed prefix. Requested
  simultaneous backing/output bytes are bounded by 2L+3; this is not a process
  memory bound.
* Explicit Vec requested capacities multiply/check host range and use fallible
  reservation. Pending/immediate record storage is source/node bounded; fixed
  accessor shape arithmetic uses at most 16 scalar components. Record keys,
  decoded strings and retained extension names remain source bounded. No new
  unbounded copy or multiplication drift was identified.
* Ordinary root/external/schema/conversion JSON calls use selected shared JSON
  limits. C1 captures the same mapped limits in the implicit parser; recursive
  external documents, subtree chunks and JSON-encoded extras receive that
  callback. ExpansionBudget retains presentation counters, not policy/parser.
  The explicit non-C1 producer parser and trusted bundled schema are the
  approved exceptions.
* Payload resolver errors return unchanged. The actual C1 implicit bridge
  unwraps causal Io and Validation before generic conversion; native archive
  ReadError retains causal kinds. No diagnostic-string classifier selects a
  category. The existing generic malformed-archive conversion remains outside
  the causal resolver path.
* Successful component charges/cache remain keyed by resolved payload member
  name. Same-name cache hits avoid another payload/component charge; distinct
  names remain distinct. All accessors, every mesh primitive and full POSITION
  counts per primitive retain their counter meaning. SchemaUri is the only
  returned payload document datum and stays under C1 URI/reference/read policy.
  All thirteen checks, fifteen limit fields and sorted exclusions remain.
