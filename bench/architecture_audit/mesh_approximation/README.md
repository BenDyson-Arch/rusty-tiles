# F1d1 independent artifact evidence

This is bounded evidence for the one-root approximation contract under #121.
It does not close #121/#113, approve release, or certify textured HLOD, topology,
appearance equivalence, recursive errors or general world/source coordinates.
Final source/artifact execution and separate nonauthor review are recorded
independently; see [review.md](review.md).

## Independent oracle

`tests/f1d1_oracle.py` authors indexed planar grids with exact integer positions,
separate source primitives/materials, three instances including a reflection,
absent/empty/Unicode labels, omitted materials and disjoint coincident vertex-key
components. It invokes no Rust geometry code or meshopt. The independent F1c2
Python decoder checks every full-detail source tuple, complete oriented corners,
material factors and exact omission. Its materialless correction distinguishes
an absent material from an invented default material; existing sensitive controls
were replayed after this correction.

The F1d1 oracle independently decodes root feature streams, complete sorted
variable-array membership, exact region labels, source-position candidates,
material factors/omissions, reductions and pair-work/report counts. It checks
actual decoded leaf and root geometry against boxes, and emitted child boxes
against the root with exact rational arithmetic of the stored numbers. No epsilon
masks containment defects. The combined leaf/proxy emitted-name cap is checked.

The independent certificate checker uses exact rational point-to-closed-triangle
distances, including degenerate triangles. It exhaustively pairs complete faces
in both directions. Optimal exact witnesses relax the producer's finite dyadic
witnesses: the resulting least face-pair certificate is itself a valid whole-face
surface bound, and a lower bound on the producer's witness certificate. An
emitted certificate below it fails. This verifies emitted bounds for these
fixtures; it does not independently enumerate every possible floating-point
interval-operation case in the implementation.

Rational controls include a 100 m spike, a 3 m interior hole, a degenerate 5 m
distance, and an exact tiny dyadic height near the admitted 1,000,000 m boundary.
An additional 2^20 arithmetic control is outside source admission and is labeled
as arithmetic evidence only. A triangle and four subdivisions have identical
support but a 4 m least face-pair certificate, demonstrating the scheme's
documented looseness without treating a sampled estimate as a bound.

Synthetic artifact controls reject invented membership, unequal arrays, false
source-triangle labels, wrong materials/defaults, non-source proxy vertices,
wrong count/work/region/appearance reports, understated certificates, zero root
error, escaped child boxes, reversed leaf winding and invented leaf ordinals.
Synthetic artifacts establish checker sensitivity, not converter acceptance.

The component checker uses authored indices to count connected components, then
requires at least one candidate face per component. A two-component coincident
fixture and a count/work-consistent one-face mutation demonstrate this necessary
condition. Identical position-only component supports cannot identify which
component authored an individual output face. Complete component retention
therefore also needs production key tests and independent source review; this
artifact checker does not claim to prove that unobservable association.

## Consumer probe

`tests/f1d1_viewer.py` and `tests/fixtures/f1d1_viewer.cjs` use provisioned Cesium
1.146.0 and Chromium/Playwright. They serve the unmodified published archive,
keep `maximumScreenSpaceError=16`, move an independently authored camera from
far to near, and observe public `tileVisible` content URLs/counts. They do not
change model matrices, private selected-tile state, geometry or feature tables.
Public `getProperty` returns all four proxy membership arrays and exact optional
labels at coarse resolution, and exact source-triangle tuples after refinement.
Queries with a label missing from the selected level must not produce matching
invented properties. This is finite local planar consumer evidence, not pixel
equivalence, unique coincident selection or a world-distance proof.

## Executed corrections and receipt discipline

The initial frozen portable source `8fe9bf6` exposed an exact manifest containment
defect when the oracle was strengthened: both grid child boxes exceed the root
by 2^-52 m on one axis although all decoded content remains enclosed.
`root-bounds-before-fix.json` pins the binary/artifact and exact stored values.
No visible browser defect is inferred from this numerical observation. Final
receipts must use the replacement source/artifact, and pass this stricter check.

Exploratory refusal cases were corrected before final evidence: a one-component
grid can legitimately reduce to one face, and a requested limit above the source
count still permits actual reduction. The final impossible-count control uses
two authored components with a one-face limit; no-reduction uses one authored
face. Error-budget rejection must reach the actual whole-face certificate gate,
and work rejection must reach the 16,777,216 complete-pair gate. Every refusal
asserts typed failure and an absent output parent, which also excludes workspace
and archive staging creation in that case.

Final receipts contain binary/source fixture/archive/member/driver digests,
exact subprocess commands/outcomes, corruption controls and browser observations.
Bulky JSON is preserved byte-for-byte in deterministic gzip with a storage index;
compression is not a rerun or broader acceptance. Lifecycle/resource probes,
full-detail profile replay and installed wheel/native checks belong to the
coordinator's separately pinned evidence.

The corrected frozen source is `0eeb906f7f043eb608a5223e2817703c6836ea4b`;
portable binary SHA256 is
`2098adf353e3d0c4eddde66b977e7a38514f7de1e3abd379051c35c2fb3d86e6`.
The strict final oracle passed grid and materialless 32→15, six-region
instances/viewer 192→44, and two-component coincident-key 64→14 cases. Fourteen
corrupted artifacts were rejected for each positive case. Twelve typed refusals
left output parents absent, including actual certificate and pair-work gates.
The corrected archive's public browser probe rendered only the 44-face coarse
root, then all 192 full-detail leaf faces at the same SSE threshold. Six coarse
array/name queries and six fine exact-triangle queries matched; the two missing
label combinations exposed no matching invented properties. These are executed
bounded observations covered by separate nonauthor review, not whole-issue
acceptance. `independent-summary.json` and `storage-index.json` give the compact
results and original-byte receipt identities.

The additional `placed_proxy_browser.py` probe publishes the same source at a
Brisbane WGS84 anchor. The independent F1c1 Decimal80 ECEF/ENU reference positions
the cameras and targets; it does not derive expected coordinates from the emitted
matrix. The public viewer still uses identity modelMatrix and natural SSE16

This finite placed-consumer observation is not an exact world Hausdorff proof.

`coordinator-storage-index.json` additionally preserves source/artifact pins,
native and installed-wheel execution, full-detail profile replays, the core
Khronos checks and the placed-browser receipt. `coordinator-checks.json` records
local test/lint log identities and unsuccessful environment setup attempts.
No converter binaries, wheel files or generated archives are checked in.

The first PR CI run exposed two stale schema-5 expectations in the active F1b3
and F1c1 resource inspectors. Rust tests passed; the PBR inspector rejected three
successful conversions, and CI had not yet reached the placement inspector.
`ci-followup.json` binds the failure, frozen native binary, before/after execution
and compressed receipts. Both inspectors now require schema 6 and exact
full-detail mode. All four PBR cases and ten placement cases passed on replay,
without changing production. These complete resource drivers were missed by the
earlier local verification. Historical audit scripts retain their original pins.

For either storage index, verify each stored SHA256 and byte length, decompress
the gzip, then verify the original SHA256 and byte length. Decompression recovers
the executed JSON bytes; it does not create new acceptance evidence. The primary
index uses its documented receipt list; the coordinator index maps original
receipt names to entries with `path`, `stored_*` and `original_*` fields.

## Near-limit resources

`resource_probe.py` and `resource-release.json` separately pin the optimized
binary from the same corrected production source, SHA256
`930142ab6abc1fa1b8c416a8b07a6051bc62e05064a22bf545d8a3054e8e1bcf`.
The accepted 64×64 indexed grid has 8,192 source faces and 1,023 proxy faces:
16,760,832 complete face pairs, 99.90234375% of the comparison ceiling. The
serial process completed in 14.81 s. Procfs samples at 10 ms observed 16,080 KiB
RSS, one thread, four descriptors and 819,911 bytes of private scratch. Raw
`wait4` peak RSS was 25,408 KiB. The matching 4,096-face target was refused at the
pair-admission gate in 0.0113 s with no output parent or scratch observed.

Raw `wait4` RSS includes the child's lifetime and may include inherited Python
launcher residency before `exec`; it is not pure steady-state converter memory.
The refusal launches after independent artifact decoding, so its 44,928 KiB raw
value can reflect the larger launcher, while short-lived procfs samples observed
only 2,588 KiB. Descriptor/thread/scratch and procfs RSS peaks are sampled and may
miss short peaks. A single host/run establishes neither total-memory limits nor
cancellation latency, constant-memory behavior or a performance guarantee.

The accepted artifact's full-detail identities, regions, original-position
candidate membership, counts, bounds and comparison work were independently
decoded. The expensive exact-rational face-pair certificate replay was omitted
at this size. Both nonempty supports lie in the same 64 m square; its exact
squared diameter is 8,192 m², below the requested 100 m budget squared (10,000
m²). This elementary whole-support reference independently justifies the
requested budget, while the reported detailed certificate of approximately
7 m is recorded without an independent near-limit replay. The child timeout is
180 s, and the driver kills and reaps its process group on timeout.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  bench/architecture_audit/mesh_approximation/resource_probe.py \
  --binary /absolute/frozen/optimized-rusty-tiles \
  --artifact-dir /absolute/new/resource-output \
  --production-source 0eeb906f7f043eb608a5223e2817703c6836ea4b \
  --expected-binary-sha256 930142ab6abc1fa1b8c416a8b07a6051bc62e05064a22bf545d8a3054e8e1bcf \
  --json-output /absolute/resource-release.json
```

## Replay

From the repository root, with an already built, frozen binary:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tests/f1d1_oracle.py --self-test \
  --binary /absolute/frozen/rusty-tiles --artifact-dir /absolute/new/probe-output \
  --json-output /absolute/portable-oracle.json
```

The driver creates five successful fixture/artifact cases and twelve admission
refusals. Use a fresh artifact directory because publication uses CreateNew.
The browser driver accepts an existing source/archive pair and explicit
`--cesium-dir`, `--node-modules`, `--chromium`, `--leaf-limit`,
`--triangle-limit`, `--max-error` and `--json-output` arguments. `--synthetic`
explicitly labels independently authored consumer feasibility artifacts.
