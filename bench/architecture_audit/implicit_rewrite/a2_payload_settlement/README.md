# A2 payload settlement replay

[audit.md](audit.md) settles the finite private fact/evaluation owner, source
profile and checked-i128 policy. These are independent read-only model controls,
not product execution or resource/conformance acceptance.

Requirements: Python 3 without `-O`, Node, the exact six source archives/member
bytes in each retained final2 artifact directory, the tracked earlier raw
receipts, and the pinned meshoptimizer reference JS at the path in `probe.py`.
Every source archive/member and the codec is verified before use. Use fresh
nonexistent output directories and run serially:

```sh
nice -n 10 python3 -B bench/architecture_audit/implicit_rewrite/a2_payload_settlement/probe.py --artifacts /tmp/rusty-tiles-a2-probe-artifacts-real-portable-final2 --work /tmp/rusty-tiles-a2-probe-artifacts-payload-settlement-portable-replay
nice -n 10 python3 -B bench/architecture_audit/implicit_rewrite/a2_payload_settlement/probe.py --artifacts /tmp/rusty-tiles-a2-probe-artifacts-real-native-final2 --work /tmp/rusty-tiles-a2-probe-artifacts-payload-settlement-native-replay
```

Each prints six observations, 23 sensitive content/scene controls and six
arithmetic controls. Compare the full `receipt.json` with
[portable-results.json](portable-results.json) or
[native-results.json](native-results.json). Results bind the executed probe,
codec wrapper, codec, inspected production bytes and original source archives.
No archives or binaries are generated by this probe. No Git, Cargo, producer,
converter or public validation API is used. Meshopt subprocesses run at priority
10 with a 20-second timeout, one at a time, and are reaped.
