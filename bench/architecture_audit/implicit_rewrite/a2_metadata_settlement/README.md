# A2 metadata/provenance settlement

[Audit](audit.md) proposes the finite initial source policy: effective inherited
REPLACE, 1.0-to-1.1 declaration promotion, exact admitted payload metadata and
known relative resources, an explicit application extras mapping and root-level
exact source manifest/report snapshots. It specifies Unsupported dispositions
for valid unproved metadata/groups/bounds/schema/extension uses and live vector
reuse, with original hash associations retained separately as historical data.

[Results](results.json) contain 36 independent model cases and 28 read-only
portable/native fixture inspections. All source/member identities match their
originating final2 receipts. Twenty-four pass the metadata profile; the four
unknown vendor-extension cases are deliberately Unsupported. This is preparation
evidence; no producer, validator, build, viewer or installed API was executed.

[Eleven inventory ownership controls](inventory-results.json) add the bounded
C1 integration rule: the admitted plan determines payload/provenance/retained-byte
roles, every role is checked before accounting, and original payloads receive
actual C1 payload inspection irrespective of report operation spelling in the
future implementation. Current public C1 does not accept the proposed snapshots;
its separate bounded A2 report profile remains an explicit implementation gate.
