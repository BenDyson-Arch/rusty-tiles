# Point-cloud 0.4 minimal acceptance

This is the point slice of the owner's 2026-10-24 approved non-mesh rescope
([#267](https://github.com/BenDyson-Arch/rusty-tiles/pull/267), section 2 and
replacement #122 Acceptance; [#268](https://github.com/BenDyson-Arch/rusty-tiles/pull/268),
“Proposed non-mesh 0.4 bar”). It retains the
[P1 source/field/voxel/lifecycle domain](../../../docs/architecture/point-acceptance-contract.md)
and [independent oracle](../../../tests/p1_point_oracle.py).

## Retained domain and decisions

Retain the source reader, synchronous partitioner, first-source-record-per-voxel
sampler, GLB metadata encoder, current implicit octree forest and F0 publication.
Every source ordinal appears exactly once in full-detail leaves, including
byte-identical records. Preserve standard dimensions, flags, RGB/NIR and admitted
scalar Extra Bytes. Decode GLB scene and tile frames when checking placement,
representatives, errors and own/ancestor bounds. No source-parser or tiler rewrite
is needed for this bar. Rework only the demonstrated CLI height-error category.

LAS/LAZ formats 0/1/2/3/6/7/8 are admitted. Local XYZ is metres; geographic input
requires a declared horizontal CRS and explicit offset to ellipsoidal height.
These checks establish local/WGS84/UTM fixtures, not every parsed CRS. Waveforms,
vector/untyped Extra Bytes, scaled 64-bit integer extras, undocumented record
tails and compound/vertical CRS are outside P1. Default/maximum points per tile
is **8,192**; default ingestion chunk is **100,000**. Neither is a whole-job RAM
cap. Explicit point delivery and its Python keyword were retired in 0.4; current
delivery is a `.3tz` implicit forest, including explicit skeleton/link tiles and
external forest documents. Historical explicit-output wording in the original
P1 receipt does not promise a retained frontend mode.

The paired script requires an installed wheel and laspy/lazrs; missing
prerequisites fail. It runs in the Python CI job. laspy is only the LAZ delivery
encoder; the test restores the literal source Extra Bytes VLR after laspy 2.7
rewrites declaration extrema. Expected records/schema always come from the
original stdlib LAS reader, not laspy.

## Receipt and limits

Final local evidence lives in
`~/.cache/rusty-tiles-evidence/040-bar-point/README.md`, with source/binary/wheel
identities, commands, metrics and a SHA-256 manifest. Bulk inputs, archives and
build intermediates remain outside git and are removed after acceptance.

This finite receipt does not close the release/platform/consumer gates. Broader
source/CRS/backend matrices, hostile-input or universal RSS bounds, exhaustive
sampling dispositions and component-ledger audits remain deferred to 0.4.x.
No browser campaign, mesh bake, new source domain or Python API is added here.
