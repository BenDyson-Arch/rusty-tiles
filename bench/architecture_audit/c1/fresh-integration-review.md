src/validate/admission.rs:214-229 checks the local signature, storage method, flags, filename and a payload range based on central-directory sizes. ## P3: opening a FIFO blocks before regular-file admission

src/validate.rs:672 opens the input before its regular-file check at :682. A POSIX FIFO without a writer blocks indefinitely inside File::open, so it never reaches the documented Unsupported outcome for nonregular files. Independent probe creates /home/bend/.cache/c1-fresh-probes/fifo.3tz with os.mkfifo and invokes frozen CLI; subprocess timeout at two seconds confirms blocking, no report emitted. This is lower priority and may predate C1; do not represent it as a new payload regression. A nonblocking open on appropriate platforms followed by handle metadata checks preserves open-file authority; a path metadata precheck alone is only a partial remedy for an opening race.
