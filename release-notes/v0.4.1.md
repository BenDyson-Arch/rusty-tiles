rusty-tiles 0.4.1 makes large jobs more practical:
- `mesh` captures faster and accepts source images larger than 32 MiB;
- `validate` scales to multi-gigabyte archives;
- a stopped run now cleans up after itself.

It also fixes mesh tiles for Blender 5.2, adds about 3,100 EPSG codes to the standard build, and adds Python helpers for CRSs and tile inspection.

## Install

- **CLI:** `curl -fsSL https://raw.githubusercontent.com/BenDyson-Arch/rusty-tiles/main/scripts/install.sh | sh` (Linux x64/ARM64, Apple Silicon macOS). For Windows x64, download the `.zip` below. Every archive is listed in `SHA256SUMS`.
- **Python:** `python -m pip install rusty-tiles`. These are CPython 3.10+ stable-ABI wheels for Linux x64/ARM64, Apple Silicon macOS and Windows x64. They need no GDAL and are tested inside Blender 4.5 LTS and 5.2 LTS.
- **Native-geospatial build:** `ghcr.io/bendyson-arch/rusty-tiles:v0.4.1` (Linux amd64).
- **From source:** `cargo install --git https://github.com/BenDyson-Arch/rusty-tiles --tag v0.4.1 --locked`

**Intel macOS is no longer supported.** 0.4.0 is the last release with Intel Mac binaries and wheels; install it with `--version 0.4.0` or `pip install rusty-tiles==0.4.0`, or build from source.

## Highlights

- **Faster `mesh` capture.**
  - Capture sizes its sorts from `--memory-budget` and runs them in parallel. On the measured meshes it is about 40% faster, and writes about 28% less scratch on an 80 M-triangle input.
  - The coarse-level incidence pass is about 28% faster.
  - Archives are byte-identical for every budget and `--jobs`.
- **Larger source textures.**
  - `mesh` no longer refuses images over 32 MiB encoded. Each image is charged against the memory budget at its real size and checked from its header before any scratch is written.
  - The limits are now 1 GiB encoded and a 16,384 px edge.
- **`validate` at scale.**
  - New `--memory-budget` and `--jobs` options, progress events, and a scratch-disk check before the run starts.
  - Scratch writes fall by about a quarter to a third.
  - On the measured archives, wall time falls 13–17% with workers.
  - Reports are identical for every budget and worker count.
- **Stopping a run cleans up.**
  - SIGINT/SIGTERM, Ctrl+C or Ctrl+Break in a Windows console, and `KeyboardInterrupt` in Python now end every long phase within seconds. The run removes its scratch, exits 130/143 and publishes nothing.
  - A `systemctl stop` no longer runs into the 90-second force-kill and leaves scratch behind.
- **Blender 5.2.** Mesh and vector tiles no longer write the default meshopt `"filter": "NONE"`, which Blender 5.2's glTF importer refused, so untextured mesh tiles open again.
- **Coarse-tile shading.** Coarse levels of meshes with normals no longer shade as starburst facets. `validate` warns about this in older archives (`coarseNormalInversion`); the warning never fails validation.
- **CRSs in the standard build.**
  - About 3,100 more EPSG codes are accepted, including GDA2020/GDA94 MGA, NZTM2000 and ETRS89 UTM. Each was checked against GDAL/PROJ to within 1 mm.
  - Reports name the datum operation used and its stated accuracy.
  - `doctor --source-crs` and Python `resolve_source_crs()` / `supported_epsg_codes()` check a CRS without converting.
- **Python tile inspection.** `list_tiles()` lists an archive's tiles. `decode_tile()` returns one as a plain GLB (meshopt decoded, textures as PNG) or as NumPy arrays, for display in tools such as Blender.
- **Releases ship what CI tested.** Release archives and wheels are the ones the full CI run built and tested, not rebuilds. A rolling `dev` pre-release of `develop` (CLI, wheels and the `:dev` image) is published after nightly CI; install it with `install.sh --version dev`.

## Breaking and behaviour changes

rusty-tiles is pre-1.0, so options, APIs, report fields, error types and archive bytes can change in any release, including patch releases like this one. Pin a version for anything you depend on.

- **Intel macOS** binaries and wheels are removed.
- **Archive bytes:** `mesh` and vector archive bytes change (the meshopt filter field), although payloads are the same. Vector `--reuse-tileset` therefore refuses archives made by earlier versions; run one fresh conversion.
- **Error type for large images:** a source image over 32 MiB that the memory budget cannot hold is now `resource_limit` (exit 1, `ResourceLimitError`). Before, it was `unsupported` (exit 2, `UnsupportedError`) whatever the budget.
- **Validate reports:** they gain a `warnings` list. With an explicit `--memory-budget` or `--jobs` they also gain a `resources` member. `validate --memory-budget` below 512 MiB is refused.
- **Coarse-tile size:** coarse tiles of meshes with normals are 13–15% larger, because creases now split normals.

## Known limitations

- Some meshes still don't get every coarse level, sometimes including the root, on steep or overhanging surfaces and sharp creases. Full-detail leaves are always delivered, and `conversion.json` and `validate` report what was left out. Tracked in #344.
- Vector output is experimental.
